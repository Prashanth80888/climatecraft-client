# UI Components

Shared UI component utilities and patterns used across both applications.

## Source

All UI styles are defined once in `shared/css/main.css` and imported by both apps.

## Shared Components

| Component | CSS Class | Used In |
|---|---|---|
| Button (solid) | `.btn-solid` | Client + Admin |
| Button (line) | `.btn-line` | Client |
| Button (solid-inv) | `.btn-solid-inv` | Client |
| Button (tiny) | `.tbtn` | Admin |
| Navigation | `.nav .nlink` | Client |
| Sidebar nav | `.sb-item` | Admin |
| Cards | `.mcard .pcard .sigcard` | Client |
| Tags | `.tag .tag2` | Client |
| Chips | `.chip .fchip` | Client + Admin |
| Form fields | `.field .fld` | Client + Admin |
| Badge | `.badge .mbadge .pill` | Client + Admin |
| Toast | `.toast` | Admin |
| Drawer | `.dr` | Admin |

## Layout Components

| Component | CSS Class | Used In |

| Wrapper | `.wrap` | Client |
| Grid 2-col | `.grid2` | Admin |
| Stats grid | `.stats` | Admin |
| Media grid | `.mgrid` | Admin |
| Table | `.tbl` | Admin |
